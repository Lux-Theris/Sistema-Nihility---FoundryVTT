## Data model (Item Geral, `system.*`)

- `device`: `enabled`, `nature` (`tech` | `technomagic`), `slots` (int >= 0, default 2), `reserveMax` (50), `reserve` (50), `accepts` (`any` | `invasion` | `weapon`), `rechargeRest` (true), `rechargeCell` (true), `rechargeAction` (false), `actionAmount` (10), `infinite` (false), `state` (`normal` | `off` | `damaged`), `offMode` (`combat` | `time`), `offCombatId`, `offSince` (world seconds), `offRounds` (3), `programs: [{uid, sourceItem}]`.
- `program`: `enabled`, `slotsUsed` (>= 1), `costPerUse` (0 = use the granted Skill's Cost; > 0 replaces it), `fits` (`any` | `weapon`), `invasion: {enabled, minigame: "sequence", target: "tech", prepRounds}` (stored only; the Invasão lot uses it).
- `consumable.energyCell` (boolean): marks the "Célula de energia".
- Skill `engineering` (boolean, "Engenharia"): configuration, not state, so it is in every copy list (`GRANTED_MECHANIC_FIELDS`, `evolveSkill`, `REQUEST_MECHANIC_FIELDS`, `sanitizeSkillMechanics`) and has a checkbox in `item-skill-general.hbs`.

## Hosts: where a placa lives (1.126.0)

A **host** is a placa's address. One scheme, used by every function in `devices.js` (sheet buttons carry it in `data-device-ref`, the repair relay in `hostItemId`, the curto card in its flag, the Skill key in `device:<ref>:<uid>`):

- **Item host:** the ref is the Item id; the host object is the Item document itself (a General Item with `system.device.enabled`).
- **Mod host:** a placa inside an implant/prosthesis **installed on a Body Part** (the whole Item lives in `mod.sourceItem`). The ref is `<part id>~<mod uid>` (`modHostRef`, `parseHostRef`; `~` never appears in an Item id and the key regex is `[^:]+`, so the key stays parseable). `mod.uid` is a new `installedMods` field, stamped by `installImplant`; a mod without one (installed before 1.126.0) falls back to `idxN` (`modUidOf`), which only holds while that part's list order does not change. The host object is a `ModDeviceHost`: it looks like an Item (`id`, `name`, `system`, `uuid` = the part's, `type: "item"`, `isMod`, `update`) and `update(changes, options)` **rewrites the part's whole `installedMods`** (deep clone, mod found by uid, `setProperty` on `sourceItem`), never an index path. Writes to two mods of one part must be sequential (`rechargeOnRest` and `empHitDevices` are).
- `hostEquipped(host)`: a mod host always counts as worn; an Item host only when equipped. Everything that read `host.system.equipped` (bonuses, PEM, panel) goes through it. Suppression is `sourceSuppressed(actor, host)` (the host reports `type: "item"` and a technomagic `device.nature` makes it magic).
- **Moving a placa between the two forms** (drop an Item with programs on a Body Part, or remove the implant): the granted Skills of its programs change key (`device:<old>:<uid>` to `device:<new>:<uid>`) through `rekeyHostGrants`, keeping level and XP; `installImplant`/`uninstallImplant` call it. Deleting a Body Part removes the grants of every placa inside (`removeDeviceGrants`, now also hooked for `body_part`).
- Known limit: "Desfazer uso" only refunds the Reserva of an **Item** host (`UNDO_ITEM_PATHS` snapshots Item fields); the Reserva of a mod host is not refunded. Validar Mundo checks only Item hosts (`deviceProgramIssues`).

## Active program upkeep (1.126.0)

`drainCharacterUpkeep` (`skills/upkeep.js`) asks `deviceUpkeepHost(actor, skill)` per source. A Skill granted by a program is paid from the host's Reserva each turn (`upkeepDeviceStep`, pure): technological with no Reserva, or a host that is off / damaged / suppressed, **switches the Skill off** like Mana at 0 (same `deactivateUpkeepSource`, Voz do Mundo notice); technomagic spends what is left and pays the difference in energy, and switches off if the energy is short too; infinite is free. Reservas are simulated in memory across the `steps` (Acelerado) and written once per host (`commitUpkeepReserve`, floats "−N Reserva"). The chat card line reads "-N Reserva de <placa>". "Mana em 0 desliga todas as Ativas" (`shutdownActiveSkillsOnDepletion`) now **skips** program Skills: they live on the Reserva. Known limit: with the energy pool disabled in the rules, `tickActorUpkeepSkills` returns before draining, so a program's per-round upkeep is not charged either.

## Rules (dono, 27/11)

- **Nature:** a placa is always tech (`itemIsTech` returns true when `device.enabled`, even with the tech box unchecked); `technomagic` is also magic (`itemIsMagic`, used by `itemNature` and `sourceSuppressed`), so Antimagia reaches it too. A placa is suppressed by PEM like any tech Item.
- **Install/uninstall is free** (anyone who can edit the actor). The program Item is stored whole in `device.programs`; one unit leaves the inventory; the granted Skill gets `grantedBySource = device:<host item id>:<uid>`. Uninstall returns the Item and removes the Skill; the Skill's level and XP travel in the returned Item's flag `deviceSkillProgress` and are restored on reinstall (implants do not do this; the placa does). Always rewrite the whole `programs` array. `programFits` refuses when slots are full or `accepts`/`fits` do not match (`fits: "weapon"` needs `weapon.enabled` on the host).
- **Passive bonuses** (`attributeBonuses`, `statModifiers`, "Quando → Então") of an installed program count only while the host is **equipped** and `deviceWorksNow` (state normal, not off/damaged, not suppressed). Not wired: `regen` of a program.
- **Paying (the hook):** `skill-effects.js` step `payDeviceReserve`, between `resolveCostAndInvestment` and `startPreparationIfNeeded`. For a Skill whose `grantedBySource` starts with `device:` it plans the payment (`planDevicePayment`): placa not working gives a warning and nothing is spent; Reserva covers it, so Reserva goes down and Mana 0; short on a tech placa is "sem Reserva" and blocked; short on a technomagic placa spends what is left and the **difference** is paid in energy through the normal path (`ctx.paid` becomes that difference; if the energy is short too, nothing is written); infinite is free. The plan is only **written** later (`commitDeviceIfPlanned`, inside `payUseCost` or after the Preparo first-part check), so a use stopped by a later step (Reverter shortfall, Mana short for the Preparo) spends no Reserva. Desfazer uso refunds the Reserva because `system.device.reserve` is in `UNDO_ITEM_PATHS`. Per-round upkeep of an Active program Skill and placas inside installed implants are covered below (1.126.0).
- **Recharge:** `rechargeOnRest` runs inside `applyRest` (both short and full rest). `rechargeWithCell` consumes one Item whose `consumable.energyCell` is true (`consumeUse`) and fills the Reserva. `rechargeByAction` adds `actionAmount`, only outside a started combat the actor is in.
- **PEM:** `applyDispel(kind "tech")` on a character calls `empHitDevices` (step 6): each **equipped** placa loses Reserva by the ship formula (`empDrainPercent`: 5% x reach, 5-75%, shared with `applyEmpToShip`, of the placa's maximum; infinite is not drained) and rolls `curtoChanceOnEmp` (default 25%) for a short circuit.
- **Curto:** options `shortLeveMax` (60) and `shortGraveMax` (95): leve gives `off`, grave gives `damaged`, above is desastre = `damaged` + Elétrico (`lightning`) damage to the wearer `round(2d6 * reserveMax / 6)` **only if the host Item has `implant.enabled`** (card with the usual Aplicar). `off` ends with the end of the combat it started in (`offMode: "combat"`, read through `liveDevice`, cleaned on `deleteCombat`), or 3 rounds of world time outside combat (`offMode: "time"`, `CONFIG.time.roundTime` or 6 s per round, cleaned on `updateWorldTime`). The chat card carries flag `deviceShort`; the GM sees "Desfazer".
- **Repair:** `repairDevice` (GM direct) sets `normal`. Players go through relay `deviceRepair` (`requestDeviceRepair(engineer, target, hostItemId)`): the GM side rebuilds everything from the sheets, requires an `engineering` Skill on the engineer, and asks the GM for approval (DialogV2 confirm) when the placa belongs to someone else the requester does not own.

## Decisions the spec did not cover

- A technomagic placa short on Reserva spends the remainder and pays only the difference in Mana (not the whole Cost).
- The default placa is 2 slots and 50 Reserva.
- Hosts are actor Items **or** placas inside installed implants (see "Hosts" above).
- Only worn hosts (equipped Item, or installed implant) count for bonuses, PEM and the panel; a placa in the backpack is inert and not listed in the Inventory block.
- The repair approval stays a DialogV2 confirm (no Aprovar/Recusar chat card); the result card is the styled one.
- A program Skill's float/notice on "Curto" and "Consertada" is local to the GM client that writes (only Reserva changes float on every client).
